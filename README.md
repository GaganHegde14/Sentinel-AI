# BotShield – Smart Ticket Booking Protection System

BotShield is a comprehensive full-stack application that provides a ticket booking system with built-in bot detection to prevent abuse. It uses a modern tech stack (React, Node.js, Express, MySQL, MongoDB) to deliver a seamless user experience and robust backend protection.

## Features

- **Authentication System**: Secure JWT-based registration and login.
- **Event Management**: Admin controls for creating, updating, and deleting events.
- **Ticket Booking**: User capabilities to book and manage tickets.
- **Bot Detection**: Rule-based detection using MongoDB to log and block suspicious activities like rate limiting, identical IP requests, and rapid duplicate bookings.
- **Admin Dashboard**: Visual insights into platform usage, total bookings, users, and blocked bot requests.

## Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router DOM
- Axios

### Backend
- Node.js & Express.js
- MySQL (Relational Data: Users, Events, Bookings)
- MongoDB (Logs Data: Request Logs, Blocked Requests)
- JSON Web Tokens (JWT) for authentication
- bcrypt for password hashing
